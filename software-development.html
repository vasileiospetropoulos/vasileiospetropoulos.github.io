ClearCalc — Calculator

ClearCalc is a calculator application built with React 19, TypeScript and Vite. It includes Standard, Scientific and Function modes, calculation history, a scientific keypad, an accessible Function Mode example listbox, a safe custom math-expression parser and automated tests. Tauri is used for desktop packaging.
